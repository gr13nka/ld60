# Quitters

A first person parkour story in one connected megastructure. The courier crosses the
builders' yard, balconies and service paths, meeting people along a three act route.

Run `npm install` and `npm run dev` to play. `npm run build` makes a production build.
On the development server, `?edit` opens the place editor; Ctrl+S saves
`src/places/builders.json`.

`docs/quitters.md` describes the world, story and code boundaries. The current
story placement and NPC figures are an initial pass awaiting an in game walkthrough.
